# C# Racing Game

A C# Windows Forms racing game with enemy cars, collision detection, scoring, speed progression, and replay functionality.

## About

This project is a simple racing game developed with C# and Windows Forms.

The player controls a car and moves left or right to avoid enemy cars. The game includes scoring, increasing speed, collision detection, game over handling, and replay functionality.

## Preview

![Racing Game](../game.png)

## Features

* Player car movement using keyboard controls
* Multiple enemy cars
* Timer-based game movement
* Collision detection
* Score tracking
* Increasing game speed
* Random enemy car positioning
* Game Over state
* Replay functionality
* Visual speed and score display

## Technologies

* C#
* Windows Forms
* .NET
* Visual Studio

## How to Run

1. Clone or download the repository.
2. Open the solution file in Visual Studio.
3. Build the project.
4. Run the application.

## Purpose

This project was created as a university programming project to practice C# Windows Forms, event handling, timers, randomization, collision detection, and basic game development.
